# 🌡️ Simple Temperature Converter using Ternary Operator (Java)
This Java console application converts a given temperature to either Celsius or Fahrenheit, based on the user’s input, using a compact ternary operator for conversion logic.

What It Does
- Takes a numeric temperature value as input.
- Asks the user to convert it to either Celsius (C) or Fahrenheit (F).
- Uses a ternary operator to determine and apply the correct formula:
F = (C × 9/5) + 32
C = (F − 32) × 5/9

Features
- Efficient and concise temperature conversion logic
- Accepts both lowercase and uppercase inputs (case-insensitive)
-Uses String.toUpperCase() for consistent comparison
- Clean output formatted to two decimal places using System.out.printf
